# MON_SUCRE
Trabajo colaborativo para digitalizar Mon Sucre

Nombre del proyecto

Mon Sucre. Tartas personalizadas y pastelería francesa.

Descripción

Página web para una pastelería especializada en tartas personalizadas y pastelería francesa, que también cuenta con servicio de cafetería.

Integrantes

Roberto Redondo: Product Owner.

Daniel Marco: Scrum Master.

Miguel Ángel y Marcos: Equipo de Desarrollo.

Tecnologías previstas

Todavía están por decidir.

Estado actual

Estamos en la fase inicial del proyecto, organizando las ideas y decidiendo cómo vamos a desarrollar la web.

Ramas personales

Hemos creado una rama para cada integrante, además de la rama principal main. Así podemos trabajar por separado y tener los cambios de cada uno más organizados.

Las ramas son daniel, marcos, miguelangel y roberto, además de main.

Commits y push

Cada integrante debe hacer al menos un commit con sus cambios y subirlo a GitHub mediante un push. De esta forma, queda registrado el trabajo de cada uno en el repositorio.
